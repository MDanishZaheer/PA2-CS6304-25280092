# Task 2 result files

This directory contains small, reproducible evidence generated by Task 2.
Model adapters, critic states, and optimizer states belong in
`task2_ppo/outputs/` and are ignored by Git.

Expected generated subdirectories are:

```text
standard/
clipping/
  clip_eps_0.05/
  clip_eps_0.20/
  clip_eps_0.50/
kl/
  kl_beta_0.00/
  kl_beta_0.10/
  kl_beta_0.20/
figures/
```

Do not hand-edit generated metrics. Tables and figures are derived from the
JSON/JSONL/CSV files by `task2_ppo.analysis`.
